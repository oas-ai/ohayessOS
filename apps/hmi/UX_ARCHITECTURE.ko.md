# OAS IVI UX 아키텍처

## 제품 원칙

OAS는 운전자가 한눈에 상태를 이해하고, 필요한 기능을 두 번의 터치 안에 찾도록 설계한다. 기본 테마는 Near Black 기반의 다크 모드이며, 라이트 모드는 정차 중 선호에 따라 선택한다. 화면은 고급스럽지만 장식적이지 않아야 한다. 브랜드 고유의 차분한 샴페인·청록 계열 포인트를 사용하며, 특정 제조사 화면이나 자산을 복제하지 않는다.

안전 경계는 변하지 않는다. Runtime이 freshness와 capability를 결정하고 QML은 그 결과만 표시한다. 이 HMI는 현재 읽기 전용이며 CAN 송신, 차량 제어, 운전자 감시나 ADAS 판단을 수행하지 않는다.

## 정보 구조

항상 보이는 Dock의 1차 목적지는 `홈`, `지도`, `공조`, `미디어`, `차량`이다. 각 목적지는 48dp 이상의 터치 영역을 지닌다. 2차 목적지는 차량 화면의 큰 행에서 연다.

| 1차 | 2차 목적지 | 현재 계약 |
| --- | --- | --- |
| 홈 / 차량 | 주행 상태, 도어·벨트 상태 | 속도·기어·일부 원시 신호만 표시 가능 |
| 지도 | 경로, 다음 안내, 교통, POI | 지도/경로 공급자 연결 전 |
| 공조 | 운전석·동승석 온도, 팬, 시트 | 원시 표시만 가능, 제어 불가 |
| 미디어 | 미니 플레이어, 확장 정보 | Runtime 재생 권한만 표시 |
| 차량 | Controls, Driving, ADAS, Lights, Locks, Display, Energy, Service, Software, 진단 | 모두 읽기 전용 또는 데이터 없음 |

카메라·전화·소프트웨어 업데이트는 차량 화면의 2차 목적지다. 운전 중 텍스트 입력과 긴 목록은 제공하지 않으며, 상세 정보는 정차 또는 명시적 진입 후에만 점진적으로 노출한다.

## 메인 화면 와이어프레임

```
┌ OAS · 현재 화면 ───────────────── 상태 · 테마 ┐
│  속도 / 기어       지도 또는 경로 표면           상태 요약 │
│  핵심 경고          다음 안내 · ETA               미디어/공조 │
│  차량 실루엣 · 실제 수신 상태만 시각화                    │
├───────────────── Floating control dock ─────────────────┤
│ 홈       지도       공조       미디어       차량             │
└──────────────────────────────────────────────────────────┘
```

지도 공급자가 없는 동안 중앙 표면은 “지도 데이터 연결 전”만 표시하며, 위치·경로·교통·주변 차량을 임의로 그리지 않는다. 차량 실루엣은 설명용 그래픽일 뿐 카메라나 센서 화면이 아니다.

## 토큰과 컴포넌트

- 색: 다크 `#080A12 / #121D2D`, 라이트 `#F7F9FC / #FFFFFF`, 본문 `#F4F7FF / #131927`, 보조 `#9BA9C7 / #62708A`, 상태 색은 amber/red/green만 사용한다.
- 서체: 핵심 수치 96~136px, 페이지 제목 28~32px, 본문 16~20px, 보조 정보 최소 13px이다.
- 간격: 8px 기준 단위, 화면 외곽 32px, 패널 반경 28~32px, Dock 반경 27px이다.
- 모션: 화면/선택 전환 180~240ms OutCubic. 상태 변화에는 fade만 사용하고 반복 장식 애니메이션은 금지한다.
- 공통 컴포넌트: `GlassPanel`, `StatusPill`, `NavDock`, `VehicleVisual`을 기반으로 버튼·상태 배지·세그먼트·슬라이더를 같은 토큰으로 확장한다. 기능 제어용 Toggle/Slider는 capability가 준비될 때까지 표시 전용이다.

## 반응형 규칙

1280×720부터 1920×1080은 좌측 핵심 정보 / 중앙 주 콘텐츠 / 우측 요약의 3열을 사용한다. 16:10에서는 중앙 열을 우선 확장하고, 3840×1200 같은 ultra-wide에서는 좌·우 보조 열을 고정 폭으로 유지한다. 720p 미만은 지원 대상이 아니다.

## 상태와 상호작용

`fresh`일 때만 실제 속도와 진단 원시 값을 표시한다. `waiting`과 `stale`은 마지막 주행 수치를 숨기고 연결 상태와 복구 조건을 표시한다. 미디어는 Runtime capability와 사유를 그대로 따른다. 원시 DBC 값은 진단용이며 안전 판단이나 제어 근거가 아니다.
